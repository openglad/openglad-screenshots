before-2-joiner-10s-after-drop.png / after-2-joiner-10s-after-drop.png

    "CONNECTION LOST - RECONNECTING" banner and the "ESC: MENU" line under

    AFTER: the modal the picker raises when it gives up on the dead host and
    swaps the networked lobby client for a local one -- NETWORKING /

    dialog loop (UxShots presenter freeze) and then dismissed by button id.
    The probe calls the revert seam directly rather than running the menu
    loop, so the backdrop is whatever the canvas last held (a stale world

    host. There is no BEFORE counterpart -- pre-fix there was no revert and
    no notice; before-timeline.txt records what the joiner got instead.
